Each VM will run a small script that write the days activity every 5 minutes with the date in the date in the first line. 

Each run rebuilds the day's file so the logs are never more than a day behind. 

db_log.sh: script for database logging

fe_log.sh: script for frontend logging

be_log.sh: script for backend logging
